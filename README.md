<div align="center">

Ivy is a **European software studio** specialised in **FiveM** development. We design
and build the full stack of a roleplay server — from performant in-game UIs to the
gameplay systems, networking and tooling behind them — with a strong focus on
**quality, robustness and performance**.

</div>

## What we do

- **Front-end** — in-game NUI interfaces, HUDs and menus built as real web apps
  (React, SolidJS, TypeScript), tuned for FiveM's CEF constraints.
- **Back-end** — gameplay systems, persistence, networking and anti-cheat in Lua,
  with native tooling in C# / C++ / Rust where the workload demands it.
- **Developer experience** — fast build pipelines on Bun, typed contracts between
  client and server, and reusable, well-documented modules.
